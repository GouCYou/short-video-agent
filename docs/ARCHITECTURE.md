# 系统架构

## 服务职责

Vue3 通过 /api 调用 Spring Boot。Java 是业务权限和数据写入的唯一公共入口，MySQL8 保存用户、任务、运行事件、作品版本、资料元数据和执行任务。Redis 保存可撤销登录会话与短期执行锁。Python FastAPI 在私有网络提供 LangGraph 编排、模型适配、知识解析和 RAG。Qdrant 保存知识片段向量及检索元数据。原始文档保存在共享卷中。

Java 和 Python 的内部调用由 X-Internal-Key 保护。浏览器不接触模型密钥。所有用户任务、版本与导出接口检查所属用户，管理员接口要求 ADMIN 角色。

## 对话创作流程

首页的会话 API 保存持续讨论和需求快照。模型依据最新上下文动态选择工具，提供 A/B/C 卡片或直接回答；用户选择 D 可自定义。只有用户明确要求交付时创建制作包，包含脚本分镜、拍摄、配音和剪辑方案。局部修改由 Python 与 Java 两端按范围合并，制作包与版本在最终结果确认后原子保存。

Java 持久化队列和执行事件，Python 通过 NDJSON 实时返回执行结果，浏览器通过 Bearer SSE 接收持久事件并按序号续接。运行中的会话支持取消，取消后阻止迟到结果覆盖作品。消息使用幂等键，手动编辑校验基础版本号，重启后排队任务继续调度，过期运行标记中断并等待用户再次发起。

## 原有任务流程

GUIDED 模式执行 PLAN，先检索与生成选题，状态进入 WAITING_SELECTION。用户确认选题后执行 GENERATE。QUICK 模式自动选择角度并执行完整生成。REVISE 接收修改范围和指令，局部字段改写保留其他字段。手动编辑、AI 改写和恢复历史均保存新版本。

生成结果以固定 JSON 结构表达定位、受众、提纲、标题、开场、分段脚本、结尾和发布文案。前端提供可编辑表单。模型输出经过结构验证，不能把任意文本直接写入作品。

## 执行与恢复

耗时工作在后台执行；请求返回任务编号。任务队列在 MySQL 中持久化，Redis 锁限制重复执行。页面轮询任务详情。对运行中的任务限制删除和再次改写等冲突操作。失败记录错误，用户可重试。进程中断由过期任务恢复机制处理；恢复可从当前任务阶段重新执行，不承诺逐 Token 续传。供应商请求重试可能产生额外调用费用。

## 知识处理

文本或文件导入后提取、切分、向量化并写入 Qdrant。检索结合类别与 enabled 状态过滤。启用、停用、分类调整和删除须同步向量元数据。资料删除保留已有作品引用快照。文档重建采用可重试的确定性标识，不累计重复片段。

文件输入限制大小与格式，原始文件使用服务生成的标识命名，Python 只允许读取 KNOWLEDGE_DIR 内的文件。扫描版 PDF 不执行 OCR。检索片段是参考数据，不能覆盖系统指令。

## 范围

涵盖创作与管理工作台，不包含视频生成、实际剪辑、自动发布、支付或团队协作。预计时长为文本估算，内容质量需要实际模型与人工评测确认。
