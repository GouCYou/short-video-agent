# 验收清单

## 用户闭环

1. 注册普通用户并登录，首页初始为空且无伪造作品。
2. 创建 GUIDED 任务，填写平台、受众、风格、时长，选择知识分类。
3. 等待多个选题，确认一个后继续生成。
4. 查看脚本、分段画面建议、资料快照与执行记录。
5. 手动修改口播保存，再用 AI 只修改开场，核对其他字段不变。
6. 比较版本并恢复旧版本，旧记录仍存在，恢复生成新记录。
7. 导出文案，刷新页面、退出并重新登录，作品仍可访问。
8. QUICK 模式自动完成全流程。

## 管理闭环

导入演示文档 → 检查切分与索引 → 检索测试 → 停用后检索无结果 → 启用后重新检索 → 重建索引 → 删除资料 → 新检索无结果且旧作品引用仍保留。

普通用户调用管理员接口必须被拒绝；用户乙无法查看、修改、删除或导出用户甲的作品；停用用户后已有令牌不能继续访问；退出后令牌撤销；修改密码后旧会话失效。

## 异常与数据

- 默认真实模式缺少配置时返回明确配置错误，任务可查看失败原因与重试。
- 不支持或空文本文件索引失败有原因，不能显示为已成功。
- 模型返回非法结构、超时和限流不能覆盖已有版本。
- 任务执行中禁止相冲突的编辑/删除操作。
- 中断执行进程后任务不永久卡在 RUNNING；执行队列与作品保存在 MySQL。
- Redis 失联时身份验证不能绕过权限。
- 重复提交使用幂等请求标识时只产生一个任务。

## 质量实验

使用 AI 服务的评测脚本比较直接生成、Agent、Agent+RAG。固定主题、模型、提示条件，保存原始输出、用量、时延和失败信息。人工评分维度为主题相关性、完整性、风格适合度、事实依据与修改成本。未连接真实模型时不能给出模型质量结论。预计时长仅为估算，最终需朗读确认。
