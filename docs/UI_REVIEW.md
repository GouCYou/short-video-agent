## 注册限流修复

本机端到端测试累积注册计数 17 次，触发原本每 IP 每小时 10 次的限制。仅清理本机注册计数，没有清空 Redis 或删除用户。本机预览进程改为 REGISTRATION_MAX_ATTEMPTS=100，生产默认仍是 10 次/3600 秒。后端支持可信代理识别，Nginx 覆盖客户端转发头；无效注册参数不占配额，429 返回具体等待时间与 Retry-After。

实际前端代理注册成功；无效输入返回 400 且配额不变；使用保留测试 IP 构造限额达到的状态，实测 HTTP 429 和 36 秒 Retry-After。临时测试限流键已删除。后端新增注册与可信代理回归后，16 项测试通过。
