# 个人设置与记忆生命周期

个人设置使用独立侧导航，分为账户信息、创作默认值、画像与记忆。账户与密码分区展示，手机宽度使用三项导航和单列卡片。左侧主工具栏选中底块随路由纵向滑动，展开与收缩时跟随实际元素尺寸；尊重系统减少动态效果设置。

## 创作要求

`GET/PUT/DELETE /api/creation-defaults` 读取、保存、恢复当前账户的默认需求。服务端校验全部 Brief 字段并按账户隔离保存。新对话使用已保存默认值，恢复系统默认不会改变已有对话。

附件菜单的“创作要求”打开本次对话编辑器，`PUT /api/conversations/:id/brief` 保存当前对话要求，执行中禁止修改。对话尚未创建时先创建再应用，默认值与本次覆盖独立。“恢复个人默认”只更新待保存草稿。

## 执行记录

右侧清空按钮显示二次确认。`DELETE /api/conversations/:id/execution-records` 保存该对话的记录展示截止序号，刷新后仍隐藏之前的执行卡片。不会停止正在运行的任务，也不会删除聊天、作品或引用快照。截止序号之后的新工具调用正常显示。底层事件保留以支持恢复生成、作品版本与引用完整性。

## 记忆来源与清理

自动画像条目保存 `conversationIds` 来源列表。旧自动条目按 evidence 的逐字用户消息追溯来源。删除对话时去掉对应来源，只在没有其他来源时删除该自动条目；手动条目和其他对话的记忆保留。对话摘要随对话删除。

重新生成前清理该对话派生画像、摘要和被替换回复的处理摘要，新请求不携带这些旧记忆。完成后从实际保留的消息重新提取。失败或取消不会重新生成旧摘要。幂等重试不会重复清理。

异步提取提交前按对话锁、运行状态、完成轮次数和画像 revision 检查快照是否仍有效，删除、重试、清空或手动编辑后，旧请求的提取结果不会重新写回。

## 验证

集成测试覆盖来源删除、旧格式来源追溯、多来源保留、手动记忆保留、重试时清理和异步旧结果失效；默认值账户隔离、恢复默认、本次覆盖互不影响；清空执行展示保留证据且新执行可见。浏览器验证默认 90 秒、新对话继承、单次改成 30 秒、个人默认仍为 90 秒、恢复系统 60 秒；确认清空和刷新后零执行卡片、原文引用保留；桌面和 390px 手机布局。

## 工作区展示更新

清空工作区使用独立原生模态组件 StudioConfirm，不使用 Element Plus 确认框；没有顶部图标，支持焦点约束、Escape、取消、忙碌时禁止重复操作及开关动画。清空范围包括之前的执行卡片和历史搜索新闻链接，清空后不再从 researchSources 或作品引用重新填回右侧。引用快照仍保留在作品与后台上下文中，避免破坏作品出处。

执行记录按工具类型合并展示一次，累计耗时；同类调用进行中时保留运行指示，展开详情显示各次真实调用。新闻原文按规范化链接去重（忽略跟踪参数和片段），相同新闻标题不重复展示。清空前已经启动的旧调用在稍后完成时也不会重新显示；新调用正常进入工作区。

## 可变选项与搜索意图

当前选项协议为每组 2～5 个实际建议，按 A 起的字母顺序排列，不再追加固定的自定义项。卡片单列、等宽等高，正文截断展示；右侧三个点通过独立模态窗查看完整说明与选择内容。

点选或从详情窗使用选项，只把对应 value 放入输入框。用户可追加要求，明确发送或回车后才提交 choice 和文本；改写整段文本时清除旧选择关联。作品修改页快捷建议同样只预填。旧会话的已选状态保留，不强行重置。

公开新闻搜索使用本轮意图检查。明确改写、换角度/选项、禁止搜索和知识库/历史查找不会触发公开新闻抓取；含糊表达通过受约束的语义判断。旧新闻主题和选项原文不构成本轮搜索许可。被拒绝的调用不会执行爬虫，也不会伪装为已搜索的记录；后续可用工具中移除公开搜索。明确要求新搜索时正常检索，读取已获取的新闻快照仍可用于改稿。
