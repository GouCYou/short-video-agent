# 工作区、默认知识库与独立管理端

## 用户端

导航统一为对话创作、我的作品、知识库。侧栏展开状态在用户页面间保持。加号图标在折叠状态下居中；空作品页按剩余空间布局，内容超出时才滚动。作品筛选使用同一个滑块移动，支持方向键、Home、End 与减少动态效果偏好。账户页面放宽到 1360px，窄屏转为单列。

回复重试在选中的原消息位置进行，流式输出期间替换其展示，成功后更新同一条数据库消息。后续消息和原发送时间保留；失败或取消后显示原回答，不插入第二条结果。重试早期回复时，模型上下文截断到该回复前的用户问题。

## 知识库

首次使用时为每个账户初始化三份预置资料：短视频内容结构、口播时长与自然表达、资料核验与引用。它们来自只读资源 `knowledge/defaults.json`，每个用户编辑的是自己的副本。可以预览正文、修改名称及内容、启停、删除和恢复默认。恢复只处理预置资料，补回被删除的预置条目，保留自己添加的资料。

支持文本和 Word、PDF、PowerPoint、ODT、ODP、RTF、CSV 等文件。文件先解析成文本，原件随即移除；保存资料不要求 Embedding。修改正文后旧索引失效，须重新建立索引。管理面板显示待建立索引、索引中、就绪和失败，提供单份或批量索引及检索测试。

Java 根据当前账户选取已启用且 READY 的资料 ID，通过内部请求传给 Python。Agent 的工具参数不能指定这个范围；Qdrant 在 top-k 前按文档 ID 过滤。旧公共检索接口排除私有资料。历史作品中的引用仍保留当时的快照。

本机生成模型为真实 `qiniu/conatus-free`，Embedding 尚未配置。因此当前可完整使用资料编辑和恢复；建立索引及真实检索还需要 `EMBEDDING_BASE_URL`、`EMBEDDING_API_KEY`、`EMBEDDING_MODEL`，并在配置后建立索引。没有以演示向量冒充真实检索结果。

## 管理端

管理员登录后默认进入用户端。左下角账户菜单的“管理面板”进入 `/admin`，由独立 AdminLayout 渲染，只有管理概览、用户管理、返回用户端及管理账户菜单。管理端不挂载创作侧栏、历史列表、创作按钮、对话轮询或 Agent 工作区。

管理概览展示实际账户总数、正常/停用数量、管理员数量及最近加入用户。用户管理提供角色调整与账户启停，当前账户自身的权限控件禁用。普通用户在路由与服务端均无管理权限。“返回用户端”恢复进入前的用户页面及侧栏状态；直接访问管理地址时默认返回首页。

初始化管理员为 `admin / 123456`。普通用户注册和改密仍要求至少八个字符；登录允许使用已配置的管理员密码。启动不会反复覆盖数据库中已有的密码。
