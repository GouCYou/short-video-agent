# 短视频结构演示资料

资料性质：人工编写的创作方法示例，用于系统演示，不代表平台官方算法规则或政策。

来源：本项目演示资料。

## 科普结构

开场用一个与目标受众有关的问题说明内容价值，正文围绕一个核心观点展开，用具体场景解释，结尾总结并邀请观众交流。避免在一条短视频里堆积过多主题。

## 口播与时长

口播需要留出停顿与画面展示时间。系统按字数估算时长仅能作为检查提示，最终需要实际朗读确认。技术名词应尽可能用观众熟悉的表达解释。

## 信息依据

数字、政策、专业结论等内容需要参考可靠资料，并记录原始出处。风格案例只用于学习表达方式，不能作为事实依据。缺少依据时应明确提示补充，不能编造来源。
