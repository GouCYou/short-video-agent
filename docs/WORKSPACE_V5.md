# 对话入库、批量导入与独立侧栏

## 实现

- 工具栏与对话列表是独立组件和列，各有显示/隐藏按钮，状态在用户页面之间保持。两栏都隐藏时，页头仍保留恢复按钮。窄屏使用可关闭的对话抽屉。管理端仍使用自己的布局。
- 对话中明确要求将文字或附件存入知识库时，Agent 使用 `save_knowledge`，右侧显示真实保存结果及资料入口。文字必须来自用户提供的原文；文件由后端复制该对话已发送附件的完整解析文字，不经模型改写。只阅读或总结文件不构成入库授权。
- 保存回调由内部凭据认证，以运行记录推导所属用户，只允许当前活动任务写入。过期任务、其他对话附件、模型编造的正文均拒绝。记录文字/文件的来源类型与来源标识。
- 相同账户重复导入相同正文会复用现有资料，保留原名称和启停设置。不同账户分别保存，不能互读。已停用的重复资料继续保持停用状态。
- 可一次选择或拖入最多 20 个文件，单文件 20MB、合计 100MB，支持 Word、PDF、PPT、ODT、ODP、RTF、CSV、TXT、Markdown。逐份返回结果，成功文件保留，失败项可重试。
- 可导出便携 JSON 知识包，再通过批量导入还原。知识包包含正文、分类、来源链接、启停与分块设置，不携带账户 ID、内部资料 ID、索引向量或服务凭据。最多 100 份，正文合计 200 万字符。
- 分块长度与重叠长度按资料保存，可在编辑器中预览。预览与实际索引使用同一分块方法，预览不调用 Embedding。修改正文或分块设置使旧索引失效；重建时替换旧分块，避免残留旧版本。
- Agent 与批量导入会在真实向量模型及向量服务可用时自动提交索引任务。已保存、索引中、已可检索和停用状态分别报告。缺少配置时保存仍成功，回执明确表示尚未建立索引。
- 当年消息时间戳仅显示月日、时分；跨年消息显示年份。首次用户消息和相隔至少 30 分钟的消息显示时间戳，其余消息不重复显示。
- 思考时长和工具耗时统一显示整数，满 60 秒按分显示，满 60 分按小时显示；不足一秒显示“不到 1 秒”。按实际完整秒数取整，避免提前进位。

## 参考与取舍

参考 [Dify 的资料管理](https://docs.dify.ai/en/cloud/use-dify/knowledge/manage-knowledge/maintain-knowledge-documents)、[分块设置和预览](https://docs.dify.ai/en/cloud/use-dify/knowledge/create-knowledge/chunking-and-cleaning-text) 以及 [LangChain 的工具式检索](https://docs.langchain.com/oss/python/deepagents/retrieval)。采用对话工具与资料面板共用同一个私有知识库，配合可预览、可去重、可重建、可追溯的导入流程。

当前保留单层分块和向量检索。混合检索、Reranker、父子分块、扫描件 OCR、在线网页采集与同步尚未实现。真实 Embedding 尚未配置，因此本轮验证的是实际解析、入库、所属用户范围和工作流，不能替代语义检索召回质量的验收。
