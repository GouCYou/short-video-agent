# 新闻检索与环境安装修复

## 检索链路

公共新闻搜索索引、媒体 RSS/Atom、公开新闻目录与网页搜索共同发现候选文章。新闻索引的聚合链接解析为出版方原文后才进入来源记录；无法解析、来源域名未接入、私网地址或抓取被拒绝时，不虚构正文。

所有入口统一按主体与关键词过滤，读取前再次校验，已解析的正文标题也必须匹配。明确来自新闻索引的候选优先读取，避免快速返回的普通网页占满候选列表。购物、报价、品牌目录和行情页面不作为新闻；普通网页必须具有发布时间或文章元数据才保留。

发布方元数据优先于新闻订阅中的发布时间。网页搜索 RSS 自带时间不当成原始发布时间；无法确认时保留未知状态。公开目录的抓取时间也不作为发布时间。搜索结果是新闻材料，不代表已独立核实报道中的全部事实。

`searchStatus` 区分 `FOUND`、`NO_MATCH` 和 `UNAVAILABLE`。本次未获取到报道不等于报道或事件不存在。不同网络能访问的索引可能不同，索引失败会保留说明；缓存有效期为三分钟。

## Mac 安装队列

安装器不再将剩余包列表作为子进程标准输入。Homebrew 子进程使用独立空输入，安装某个包不会吞掉后续 Redis、Maven 等任务。再次执行只补齐未安装的环境，不重装已完成项。安装失败的摘要在终端显示一次，完整原因保存在 `.runtime/local/install.log`。

## 验证

- 自动测试覆盖：完整安装队列、子进程读取标准输入、镜像回退、多个领域的相关性、聚合链接解析、新闻候选排序、网页与新闻区分、原文标题复核与原始发布时间。
- 真实公开网络查询验证：`iPhone duo` 与 `比亚迪`，原文链接及响应快照保存在开发机忽略目录 `.runtime/`。
