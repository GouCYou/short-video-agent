# 知映 · 短视频创作工作台

Vue 3、TypeScript、Vite、Element Plus、Pinia 和 Vue Router 构建的用户端与管理端。所有业务数据来自 Spring Boot `/api`，没有伪造的前端生成结果。模型密钥只在 AI 服务端配置，不得放入 `VITE_*` 环境变量。

## 本地运行

推荐 Node.js 22.22.2 以上或 24.15 以上版本。

```bash
npm ci
cp .env.example .env.local
npm run dev
```

默认访问 `http://localhost:5173`。Vite 将 `/api` 转发至 `http://localhost:8080`；后端端口不同时设置 `VITE_PROXY_TARGET=http://127.0.0.1:18080`。`VITE_API_BASE_URL=/api` 通常保持不变。后端需先配置 MySQL 8、Redis 与内部 AI 服务。

用户直接注册；管理员由后端环境变量初始化，不在浏览器中预置密码或管理权限。

## 对话工作台

首页 `/` 和 `/conversations/:id` 使用「导航轨 / 对话历史 / 聊天 / 工作区」布局。首次发送才创建对话；支持自由聊天、选题/方向/受众/风格/制作方式的 A/B/C 选择和 D 自定义。历史可搜索、重命名、删除。

工作区显示真实工具执行记录、完整制作方案与引用资料。方案包含稳定编号分镜、拍摄安排、设备与道具、配音稿与录音要点、剪辑步骤和发布文案。可展开阅读、手动编辑、比较版本、恢复、定稿并导出。拍摄、配音、剪辑均为可执行的文字制作方案，不生成视频或音频文件。

流式更新通过带 Bearer 认证的 `fetch` SSE 读取，URL 不含 token；按持久化事件序号去重、重连，断线时每 2 秒查询详情和新增事件。停止请求由服务端中止当前运行；离开对话会取消浏览器连接与计时器，已有服务端任务继续运行。Nginx API 代理关闭响应缓冲，防止流式事件被积压。

旧任务页 `/tasks`、管理端和个人设置继续保留。

## 其他功能

- 用户注册、登录、会话过期处理、个人信息与密码修改。修改密码后回到登录页，使用新密码重新认证。
- 真实任务统计、作品列表搜索与状态筛选、复制需求、删除作品。
- 引导创作和快速生成，知识库分类范围与 RAG 开关。网络失败后重试相同创建请求沿用 Idempotency-Key。
- 活动任务每 2 秒查询详情；离开页面后清理计时器，任务在服务器继续运行。
- 选题确认、结构化脚本、人工编辑、AI 指定片段优化、引用快照、运行记录。
- 不可变版本列表、左右内容对比、历史内容恢复为新版本、复制文案、Markdown/TXT 导出。
- 管理端用户权限、知识文件/文本导入、分类与来源、索引状态、知识片段预览、启停/重建/删除、检索测试、全站任务与服务状态。

文档支持 `.txt`、`.md`、`.docx` 与可提取文本的 `.pdf`，单文件最多 20 MB。扫描 PDF 不提供 OCR。

生成模型、Embedding 和 Qdrant 未配置时显示真实错误。仅在后端/AI 显式启用演示模式后，系统才能返回演示内容；管理页会标识演示模式。配置存在不代表已经验证供应商密钥，真实模型可用性以实际调用为准。

## 验证与构建

```bash
npm test
npm run build
npm run preview
npm audit
```

Vitest + Vue Test Utils 在 jsdom 中验证身份流程、错误状态、结构化编辑与纯文本安全、选题确认、轮询清理、路由竞态与创建重试幂等键。测试桩仅在测试文件内，应用代码不使用测试数据。组件测试不替代浏览器视觉验收或真实模型质量验收。

生产构建输出到 `dist/`。Dockerfile 使用 Node 构建及 Nginx 托管，`nginx.conf` 将 `/api` 转发到 Compose 服务名 `backend:8080`；单独部署时按实际后端地址修改它。SPA 路由刷新已配置回退至 `index.html`。

根目录的 `deploy/` 与项目 README 提供整套服务部署与 API 配置说明。
